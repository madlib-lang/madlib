Kind mismatch
'String' has kind *,
but 'List' has kind * -> *.
Note: Kinds describe how many type arguments a type constructor takes.
'*' means a fully-applied type (like 'Int' or 'String').
'* -> *' means a type that takes one argument (like 'List' or 'Maybe').
Hint: Check whether you applied too many or too few type arguments.
